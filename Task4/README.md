# Задание 4. Формируем BPM-процесс

По итогам обсуждения реализации оркестратора было решено использовать BPM-движок, так как он позволяет наглядно
визуализировать процесс и вовлечь в проектирование бизнес-экспертов. Теперь ваша задача — построить BPMN-диаграмму,
отражающую весь процесс обработки платежа. Она должна показывать как успешные, так и компенсационные развилки, включая
шаг с возможным ожиданием ответа после ручной антифрод-проверки. Подумайте, как удобнее показать параллельные действия,
где разместить pivot-точку и как отразить автоматические возвраты.

По итогу выполнения задания у вас должна получиться BPMN-диаграмма, которую можно будет впоследствии использовать как
основу для реализации оркестрации в BPM-движке. Вы можете выполнить её в любом удобном редакторе (Camunda Modeler,
Draw.io, PlantUML с bpmn-расширением). Диаграмма должна быть представлена в виде простой картинки в формате PNG или JPG.

Получившийся артефакт загрузите в репозиторий в директорию Task4.
