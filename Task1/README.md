# Задание 1. Проектируем шаги Saga

Прежде всего вам нужно проанализировать описание процесса и выделить все транзакции, задействованные в нём. Для каждой
транзакции определите её тип: компенсируемая, необратимая или повторяемая. Не забудьте указать компенсируемые
транзакции.

Для описания используйте шаблон:

## Шаблон

| Транзакция                                                 | Описание                          | Тип                                          | Компенсация                            |
|------------------------------------------------------------|-----------------------------------|----------------------------------------------|----------------------------------------|
| (Лучше приводить в формате кода, например, CREATE_PAYMENT) | (Описание шага в свободной форме) | (компенсируемая / необратимая / повторяемая) | (наименование шага из первого столбца) |

По итогам анализа у вас должна быть таблица-реестр транзакций Saga-оркестрации. Она может быть представлена в формате
Markdown или также в виде картинки в формате PNG или JPG. Получившийся артефакт загрузите в репозиторий в директорию
Task1.
