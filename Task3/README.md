# Задание 3. Решаем, где расположить оркестратор

Команда OrchestrPay очень довольна результатами вашей работы и теперь гораздо лучше понимает, как будет реализован
процесс. Сейчас перед вами стоит вопрос: где разместить функцию оркестрации — внутри одного из доменных сервисов или в
отдельном сервисе-оркестраторе?

Вам необходимо принять серьезное архитектурное решение, поэтому подготовьте ADR, где опишите оба варианта, сравнив
плюсы-минусы и сделав выбор в пользу одного из вариантов.

Чтобы сдать решение в формате ADR, используйте [шаблон](adr_template.md).

В результате у вас должны получиться ADR. Загрузите его в директорию Task3 вашего репозитория.
