# Задание 5. Добиваемся качества реализации

Когда архитектура построена, а бизнес процессы описаны наступает этап проверить корректность работы системы. Для этого
её нужно покрыть тестами, которые будут проверять, как основной flow, так и corner cases и сигнализировать при
возникновении ошибок, чтобы их оперативно исправить

Опишите набор интеграционных и end-to-end тестов и представьте их в виде таблице по образцу:

| Название | Тип | Компоненты | Предусловия |
|----------|-----|------------|-------------|
| ...      | ... | ...        | ...         |

По итогу выполнения у вас должна быть таблица тест-кейсов. Она может быть представлена в формате Markdown или также в
виде картинки в формате PNG или JPG. Получившийся артефакт загрузите в репозиторий в директорию Task5.
